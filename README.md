# Agent 面试工作台

> 另有 **桌面版「面试助手」**：上传简历出大白话面试题、录音转写、五维评估（专业度 / 自驱力 / 性格特质 / 逻辑思维 / 适应力），支持智谱 GLM 与 DeepSeek。见 [desktop/README.md](desktop/README.md)。

**入口只有一个：`index.html`。** 打开即可使用，无需联网、无需安装。

- **通用题池**（440 题）和**评估方法**直接可用。
- **简历板块**已加密：点「简历板块」，输入密码即可解锁；勾选「在本机记住密码」后，下次打开自动解锁。
- 每个板块、每个分块都有自己的地址，例如 `index.html#/resume/C/C-p2`，可收藏或发给同事（对方同样需要密码）。

打开方式（任选其一）：
1. 在 GitHub 上下载 `index.html`，双击打开；
2. 开启 GitHub Pages（Settings → Pages → Deploy from a branch），之后直接访问 `https://keanying.github.io/mianshi/`。

## 题目怎么组织

和桌面版一致，按五个维度考察、每项 0~5 分（规则见 [docs/五维题规范.md](docs/五维题规范.md)）：

| 维度 | 看什么 |
|---|---|
| 专业度 `pro` | 做过的事是否真懂：原理、取舍、踩过的坑，数字怎么量出来的 |
| 自驱力 `drive` | 主动找事做、主动学、主动推动，而不是等安排 |
| 性格特质 `trait` | 沟通、合作、抗压，面对分歧和批评时的反应，是否坦诚 |
| 逻辑思维 `logic` | 先结论后原因、有条理，数字和因果对得上，分得清个人和团队 |
| 适应力 `adapt` | 条件变了、遇到没见过的问题，能不能想出办法并说清为什么 |

- **通用题池**：每题带维度标签、深挖追问、「情景变更」、高分信号和风险信号；含「五维通用题」（每个维度 8 道大白话题）、「项目表达与情景应变」分类，以及从简历中去个人化后沉淀的通用题（「源自简历」）。
- **简历板块**：每份简历一个独立板块，按简历分块（专业技能 / 工作经历 / 每个项目）出题，块内按「逻辑思维 → 专业度 → 适应力」排列；另有「五维题」标签，按五个维度各 6~10 道贴着这份简历的大白话题。附核实点、面试策略和五维打分（0~5 分，只存本机）。
- **评估方法**：用人画像、60 分钟流程、0~5 分评分锚点、风险信号。
- **面试模式**：右上角进入，全屏一次一题；←/→ 切换，空格显示要点，A 标记已问，Esc 退出。

页面、题目和答案的逐项梳理见 [docs/梳理与调整.md](docs/梳理与调整.md)。

## 新增简历

把简历截图发给 Claude 即可，处理步骤见 [docs/新增简历流程.md](docs/新增简历流程.md)。新简历会追加为新板块（G、H…），已有板块不受影响。

## 维护者

```
index.html                 唯一入口（构建产物，已提交）
vault/resumes.enc.json     简历原始数据（转录 + 板块题目）的加密包
data/pool/                 通用题池：base 原题、enrich 补充字段、added 新增题、curation 主维度与精简
src/                       页面模板；scripts/ 构建、加解密、浏览器检查；docs/ 规范与流程
private/                   解密后的简历数据与本机密码（.gitignore 排除，不提交）
```

```bash
python3 scripts/vault.py open    # 新环境：用密码把 vault 解到 private/resumes/
python3 scripts/build.py         # 生成 index.html（简历板块用同一密码加密内嵌）
python3 scripts/vault.py seal    # 简历数据有改动时，重新加密写回 vault
node scripts/check_ui.js         # 浏览器检查（需 Playwright）
```

加密方式：PBKDF2-SHA256（60 万次迭代）派生密钥，AES-256-GCM 加密。仓库是公开的，密文任何人都能下载，安全性完全取决于密码强度：不要换成短密码，也不要把密码写进仓库。
