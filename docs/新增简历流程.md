# 新增简历流程

简历会持续加入。每份简历是一个**独立板块**；已有板块的题目、已问记录和打分不会因为新增简历而改变。使用者只需要把截图发给 Claude，下面是处理方的步骤。

## 步骤

0. **准备**（新环境）：`python3 scripts/vault.py open`，输入密码，把已有简历数据解到 `private/resumes/`。
1. **分配编号**：按收到顺序取下一个字母（A、B、C、D 之后是 E、F…，超过 Z 用 AA、AB…）。编号一经分配不再变更，本机记录按编号保存。
2. **转录原文**：写入 `private/resumes/<编号>/resume.md`，保留简历原有分块（专业技能 / 工作经历 / 每个项目），末尾附「观察到的核实点」。截图分辨率低时先放大分段识别，拿不准的名称标注「待核对」。
3. **出板块题**：按 `docs/题目规范.md` 和 `docs/简历板块规范.md` 生成 `private/resumes/<编号>/questions.json`：
   - 每个分块一组题，块内按「逻辑思维 → 专业度 → 适应力」排列（代码 `logic` / `pro` / `adapt`，旧代码 `exp` / `ext` 构建时自动换算），三种维度都要有；
   - 题目 id 以编号开头（如 `E-p2-3`），全局唯一；
   - 时间线、数字口径、前后矛盾等放进 `verify`；
   - 写完后对照转录逐题复核：不出现简历里没有的数字和假设；
   - 在所有分块之后追加五个「五维题」块（专业度 / 自驱力 / 性格特质 / 逻辑思维 / 适应力，每个维度 6~10 道大白话题），规则见 `docs/五维题规范.md`。
4. **沉淀通用题**：从 `poolCandidates` 中去掉与通用题池已有题重复或高度相近的，其余追加到 `data/pool/added.json`，保留 `origin` 指向来源题。只追加，不改动已有题的顺序。
5. **构建、加密、检查**：
   ```bash
   python3 scripts/build.py         # 生成 index.html，简历板块加密内嵌
   python3 scripts/vault.py seal    # 更新 vault/resumes.enc.json
   node scripts/check_ui.js         # 浏览器检查：题池、解锁、板块分块、直达链接、手机布局
   ```
6. **提交**：`index.html`、`vault/resumes.enc.json`、`data/pool/added.json`。`private/` 永远不提交。
